# 📏 Convenções — Projeto Lavo

## 🧱 Convenções de Código

- **TypeScript** com tipagem rigorosa
- Nomes de arquivos: `PascalCase` para componentes, `camelCase` para funções
- Imports absolutos com `@/` (configurado no `tsconfig.json`)
- Evitar `export *`

## 🧩 Convenções de Commit

```
feat: adiciona análise de etiqueta
fix: corrige crash na câmera
refactor: simplifica autenticação
docs: atualiza README
```

## 💅 Estilo

- 2 espaços
- Aspas duplas
- Ponto e vírgula obrigatório

## 🧠 Nomenclatura

| Tipo | Exemplo | Padrão |
|------|---------|--------|
| Componente | `CameraScreen` | PascalCase |
| Função | `handleCapture` | camelCase |
| Constante | `MAX_SIZE` | UPPER_SNAKE_CASE |
| Tipo | `User` | PascalCase |
